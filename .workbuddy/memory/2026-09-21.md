### 实现要点（后续改动时复用）
- 数独：终盘回溯生成 + 逐格挖洞并用 `countSolutions(board,2)` 保证唯一解，四档难度（保留 45/36/30/26 提示），最慢专家档约 11ms。
- 麻将连连看：144 张标准龟形牌阵，坐标以半张牌为单位，分层 87/36/16/4/1，无重复；x 方向 12 张行起点为 2/6/4/2/2/4/6/2，上层居中于 15；左右凸出牌 y=7。
- 泡泡龙：行错位用 `parity` 变量控制（`(row+parity)%2`），下压一行时先 `parity ^= 1` 再 `unshift`，否则错位行会丢最右侧一颗。
- 华容道：滑动动画按「方块数值 → 显示坐标」缓存（`disp`）缓动，不能按格子索引缓存；点击整排推动要从空格侧向点击格逐个 swap；方向键 = 方块滑动方向。
- 球球分类：飞行动画期间目标管已 push，需用 `skip[ti+':'+bi]` 跳过重复绘制。

## xiaohongshu/ —— 小红书探索页（React 19 + TS + Vite + NutUI-React）

同一天新增，commit a92761a。工程在 `xiaohongshu/`，入口 `src/App.tsx`。

### 环境事实（重要）
- NutUI React 稳定版 3.1.0（4.x 只有 beta）的 peerDependencies 只到 React 18，
  装 React 19 必须 `npm install --legacy-peer-deps`，实测 React 19.3 下渲染/交互正常。
- `@nutui/icons-react`（3.0.2）是 nutui-react 的传递依赖，已提升为直接依赖；
  **nutui-react 不导出 Icon 组件**，图标一律从 `@nutui/icons-react` 取。
- 图标 props 只有 `width/height/color/className/style`，**没有 size**。
- 组件导出名注意：是 `CountDown`（不是 Countdown）、`Tabbar`/`Tabbar.Item`、`Tabs`/`Tabs.TabPane`、
  `SideBar`/`SideBarItem`（渲染类名 `nut-sidebar`）、`Price`、`Tag`。
- `Tabs` 的 `align` 只接受 `'left' | 'right'`，要居中得靠 CSS `.nut-tabs__titles{justify-content:center}`。
- `Toast` 只有 `Toast.show({ content, duration })`（无 text/success 便捷方法）。
- `InfiniteLoading` 用 `onLoadMore: () => Promise<void>`、`target` 传滚动容器选择器（本项目 `.page-body`）。
- Address/Cascader 无 onConfirm，统一用 `onChange(value, pathNodes)`；`CascaderOption = {text,value,children}`。
- `Grid` 没有 `border` prop（只有 columns/gap/center/square/reverse/direction）。

### 结构
`components/`: Explore（搜索+主Tab+频道chips+瀑布流+无限加载）、Waterfall（按累计高度分两列）、
NoteCard、NoteDetail（Popup 全屏）、ShopPanel（Address/CountDown/Cascader/Price/Tag/SideBar）、
MessagePanel、MePanel、BottomTabBar（中间发布按钮，ITEMS 里用 'publish' 占位）。
数据全在 `src/mock/`（notes.ts / region.ts），封面头像一律 CSS 渐变 + emoji，零外部素材。
