## Additional Notes

### 1. Scope
This license covers all code, styles and documentation under the `WorkBuddy/`
directory of the `web-complex` repository, including the H5 and PC games, the
shared audio library and the shared theme stylesheet.

### 2. Game Rules
The games in this repository implement classic puzzle rules (2048, Sudoku,
sliding puzzle, Mahjong solitaire, bubble shooter, ball sort, block blast,
snake). Game rules and mechanics are not subject to copyright. Only the
original code and assets in this repository are covered by this license.

### 3. Assets
- All visuals are drawn at runtime with Canvas code. No image assets are used.
- All sound effects are synthesized at runtime via WebAudio in
  `WorkBuddy/shared/audio.js`. No audio files are loaded.
- No third-party fonts, icon sets or game engines are bundled.
